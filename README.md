pii-guard
AI에 질문이나 파일을 넘기기 전에 개인정보를 마스킹하고, 파일을 암호화하는 도구입니다.
웹 도구는 브라우저 안에서만 동작하며 입력한 내용을 서버로 보내지 않습니다.

웹 도구 사용법
텍스트 마스킹
텍스트를 붙여넣거나 텍스트 파일(txt, csv, md, json, log, tsv)을 불러옵니다.
가릴 이름이 있으면 "추가로 가릴 단어"에 쉼표로 구분해 입력합니다.
가리는 방식을 고르고 "마스킹하기"를 누릅니다.
토큰 치환: [휴대전화_1]처럼 바꿉니다. 같은 값은 같은 토큰이 되고, 나중에 복원할 수 있습니다.
별표(*) 치환: 원래 값을 알 수 없게 지웁니다. 복원할 수 없습니다.
결과를 복사하거나 파일로 저장해 AI에 보냅니다.
원본 복원: 토큰 방식으로 마스킹했다면 AI 답변을 "원래 정보 복원하기"에 붙여넣어 토큰을 원래 값으로 되돌릴 수 있습니다.
대응표는 이 페이지를 열어 둔 동안만 유지되며, 새로고침하거나 닫으면 사라집니다.
파일 암호화·복호화: 파일과 비밀번호(8자 이상)를 넣고 암호화 또는 복호화를 누릅니다.
AES-256-GCM으로 암호화하고 키는 PBKDF2-SHA256(25만 회)으로 만들며, 원래 파일명도 암호문 안에 숨깁니다.
비밀번호를 잃으면 복구할 수 없습니다.

옵션
설명
--words 홍길동,김영희
자동으로 못 찾는 이름·회사명 등을 추가로 가림
--star
토큰 대신 별표(*)로 가림 (복원 불가)
--map
토큰과 원래 값의 대응표(_map.json)를 저장. 이 파일에는 개인정보가 들어 있습니다.
--encrypt
개인정보가 든 원본 파일을 비밀번호로 암호화한 .enc 파일도 함께 생성
원본은 수정하지 않고 이름_masked.확장자로 새로 저장합니다.
형식
처리 방식
Word (.docx)
본문, 표, 머리글·바닥글. 서식은 유지됩니다.
Excel (.xlsx)
셀 값. 숫자로 저장된 주민번호·카드번호도 처리합니다.
PDF (.pdf)
글자만 추출해 이름_pdf_masked.txt로 저장
텍스트 (.txt .csv .md .json .log .tsv)
그대로 처리
-encrypt로 만든 .enc 파일은 웹 도구의 복호화로도 열 수 있습니다.
한계
정규식 기반이라 형식이 특이한 정보는 놓칠 수 있습니다. AI에 보내기 전에 결과를 직접 확인하세요.
PDF는 원래 레이아웃이 사라지고, 스캔본은 OCR이 필요해서 처리되지 않습니다. 표에서 줄바꿈으로 단어 중간이 끊기면 일부가 남을 수 있습니다.
Word의 텍스트 상자·각주·댓글, Excel의 메모는 아직 처리하지 않습니다.
Word, Excel, PDF 파일은 웹 도구에서 처리되지 않습니다. pii_guard.py를 내려받아 로컬에서 실행하세요.
파이썬 도구에는 아직 복원 기능이 없습니다.
주의
이 저장소에 실제 개인정보가 든 파일을 올리지 마세요. 마스킹 결과(*_masked.*), 대응표(*_map.json), 암호화 파일(*.enc)도 올리지 않도록 .gitignore에 등록해 두는 것을 권장합니다.
test_samples/의 파일은 모두 가짜 정보입니다.
