# 🛡️ pii-guard

**ChatGPT·Claude 같은 AI에 글이나 파일을 보내기 전에,<br>주민번호·전화번호 같은 개인정보를 자동으로 가려 주는 도구**

### [👉 지금 바로 써 보기](https://sejin0211.github.io/pii-guard/)

설치 없이 · 회원가입 없이 · 인터넷 창에서 바로

</div>

---

## 🙋 이런 분께 필요해요

- 민원·상담 기록을 AI로 **요약**하고 싶은데, 안에 주민번호와 연락처가 들어 있다
- 신청자 명단 엑셀을 AI에게 **정리**해 달라고 하고 싶다
- 고객에게 보낼 **답장 초안**을 AI에게 부탁하고 싶은데, 이름과 계좌번호가 걸린다

이럴 때 개인정보를 **먼저 가린 뒤** AI에 보내고, AI가 써 준 답에서 **원래 정보로 되돌릴** 수 있어요.

## 🔒 내 정보는 어디에도 보내지 않아요

모든 작업은 **지금 보고 있는 인터넷 창 안에서만** 이루어집니다.
입력한 글이나 파일은 서버나 다른 곳으로 전송되지 않아요. 인터넷을 끊은 상태에서도 동작합니다. (스캔본 PDF용 OCR 엔진만 처음 쓸 때 같은 사이트에서 한 번 받아 와요.)

## 🚀 3단계로 끝

### 1단계. 글을 붙여넣고 「마스킹하기」

[웹 도구](https://sejin0211.github.io/pii-guard/)를 열고, AI에 보낼 글을 붙여넣습니다.
이름처럼 자동으로 못 찾는 단어는 **「추가로 가릴 단어」** 칸에 적어 주세요.

> **넣은 글**
> 홍길동님(주민번호 900101-1234567)의 연락처는 010-1234-5678 입니다.
>
> **가려진 결과**
> [지정어_1]님(주민번호 [주민등록번호_1])의 연락처는 [휴대전화_1] 입니다.

개인정보 자리에 `[휴대전화_1]` 같은 **이름표**가 들어갑니다.

### 2단계. 가려진 글을 AI에 보내기

「복사」를 눌러 ChatGPT·Claude 같은 AI에 붙여넣고 원하는 걸 부탁하세요.
AI는 이름표만 보기 때문에 진짜 정보를 알 수 없어요.

> 💡 **팁:** AI에게 *"대괄호 [ ] 로 된 표시는 바꾸지 말고 그대로 써 줘"* 라고 덧붙이면 다음 단계가 깔끔해져요.

### 3단계. AI 답변을 붙여넣고 「복원하기」

AI가 써 준 답을 **④ AI 답변에서 원래 정보 복원** 칸에 붙여넣으면, 이름표가 원래 정보로 돌아옵니다.

> **AI 답변**
> [지정어_1]님, 요청하신 내용은 [휴대전화_1]로 안내드리겠습니다.
>
> **복원 결과**
> 홍길동님, 요청하신 내용은 010-1234-5678로 안내드리겠습니다.

> ⚠️ **페이지를 닫거나 새로고침하면 복원할 수 없어요.** 원래 정보는 이 창에만 잠깐 기억해 두기 때문이에요. 복원을 마친 뒤에 닫으세요.

## 🔍 자동으로 찾아 주는 정보 (10가지)

| 종류 | 이런 모양을 찾아요 |
|---|---|
| 주민등록번호 · 외국인등록번호 | 900101-1234567 · 900101-5234567 |
| 휴대전화 | 010-1234-5678 |
| 일반 전화 | 02-123-4567 · (02)123-4567 · 070-1234-5678 · +82 2-123-4567 |
| 이메일 | name@example.com |
| 계좌번호 | 110-123-456789 |
| 카드번호 | 1234-5678-9012-3456 |
| 사업자등록번호 | 123-45-67890 |
| 여권번호 | M12345678 · M123A4567 (신형) |
| IP 주소 | 192.168.0.15 |
| 주소 (도로명·지번) | 서울시 송파구 위례송파로 123, 1706동 804호 · 구리시 갈매중앙로 16, 709-702 · 서울 송파구 장지동 123-4 |

- **이름·회사명은 자동으로 못 찾아요.** 꼭 「추가로 가릴 단어」에 직접 적어 주세요. (예: `홍길동, 김영희, ㈜예시컴퍼니`)
- `2026-09-29` 같은 **날짜는 가리지 않아요.** 계좌번호와 모양이 비슷하지만 따로 구분합니다.
- 주민등록번호는 앞 6자리가 **실제 날짜일 때만** 찾아요. 13자리 주문번호 같은 숫자를 잘못 가리지 않기 위해서예요.
- `０１０-１２３４-５６７８`처럼 **전각 숫자**로 쓴 번호도 찾아요.
- 주소는 **시·도(서울, 경기 등)와 시·군·구가 둘 다 있으면** 바로 찾아요. 둘 중 하나만 있으면, 일반 문장을 잘못 가리지 않도록 **동·호수(`1706동 804호`, `709-702`)까지 있을 때만** 찾아요. 그래서 `송파구 위례송파로 123`처럼만 쓴 주소는 못 찾을 수 있어요. 못 찾은 주소는 「추가로 가릴 단어」에 적어 주세요.
- 가리고 싶지 않은 종류가 있으면, 화면의 **「자동 탐지」 버튼을 눌러 끌** 수 있어요.

## 🎨 가리는 방식 고르기

| 방식 | 결과 모양 | 원래대로 되돌리기 |
|---|---|---|
| **이름표로 바꾸기** (기본) | `[휴대전화_1]` | ✅ 가능 |
| 일부만 가리기 | `010-****-5678` · `901023-1******` · `서울시 송파구 위례송파로 ***, ****동 ***호` | ❌ 불가 |
| 별표로 가리기 | `***-****-****` | ❌ 불가 |

세 방식 모두 **텍스트와 파일(Word·Excel·한글·PDF)** 에서 고를 수 있어요. 가린 파일을 **업무에 다시 쓰려면 「일부만 가리기」** 가 좋아요. 앞뒤 일부가 남아 누구의 정보인지 확인하기 쉬워요.

AI 답을 다시 원래 정보로 돌려야 한다면 **이름표 방식**을 쓰세요.
같은 정보는 항상 같은 이름표가 붙어서, AI도 "1번 사람과 2번 사람은 다르다"는 걸 구분해 답할 수 있어요.

## 📁 Word · Excel · 한글 · PDF 파일도 돼요

화면 위쪽 **「2. 파일 마스킹」** 탭에서 파일을 끌어다 놓고 「파일 마스킹하기」를 누르면, 가려진 파일을 내려받을 수 있어요. 여러 개를 한 번에 넣어도 됩니다.

| 파일 | 이렇게 처리해요 |
|---|---|
| 📘 Word (.docx) | 글꼴·굵기 같은 **서식은 그대로**, 개인정보만 가려요. 표·머리글·각주·댓글·글상자·링크도 포함 |
| 📗 Excel (.xlsx) | 서식은 그대로, 셀·메모·링크 속 개인정보를 가려요 |
| 📙 한글 (.hwpx) | **서식은 그대로**, 본문·표·머리말·각주·필드 값 속 개인정보를 가려요. 첫 쪽 미리보기 그림은 빈 그림으로 바꿔요 |
| 📙 한글 (.hwp) | 글자만 뽑아서 **텍스트 파일(.txt)** 로 저장해요. 서식을 유지하려면 한글에서 **.hwpx로 저장**해 넣으세요 |
| 📕 PDF | 글자만 뽑아서 **텍스트 파일(.txt)** 로 저장해요. **스캔본은 OCR로 글자를 읽어요** |
| 📄 텍스트 (.txt, .csv 등) | 그대로 가려요. 한글이 깨지는 옛날 형식 파일도 처리해요 |

- 작업이 끝나면 결과 파일을 **한 번 더 검사**해서, 남은 개인정보가 있으면 ⚠️로 알려 줘요.
- 「문서 속성도 지우기」를 켜 두면 파일에 숨어 있는 **작성자·회사 이름**도 지워요.
- 옛날 형식(.doc, .xls)은 안 돼요. Word·Excel에서 **.docx, .xlsx로 다시 저장**한 뒤 넣어 주세요.
- 비밀번호·배포용 한글 문서는 글자를 읽을 수 없어요. 한글에서 풀어서 일반 문서로 저장한 뒤 넣어 주세요.

> 🔎 **스캔본 PDF(OCR)** — 글자가 없는 쪽만 골라 OCR로 읽어요. 처음 한 번은 OCR 엔진(약 9MB)을 받느라 시간이 걸려요.
> OCR은 **잘못 읽는 글자가 있을 수 있고, 잘못 읽은 번호는 가려지지 않아요.** 결과 파일을 꼭 열어서 확인하세요.
> `index.html` 파일을 내려받아 바로 열면 브라우저 보안 때문에 OCR이 동작하지 않으니, [배포된 페이지](https://sejin0211.github.io/pii-guard/)에서 써 주세요.

> 🧪 처음이라면 화면의 **「샘플 넣기」 / 「샘플 파일로 해보기」** 버튼을 눌러 보세요. 가짜 개인정보로 만든 예시로 바로 체험할 수 있어요.

## ⚠️ 꼭 알아두세요

1. **결과는 꼭 눈으로 한 번 확인하세요.** 이 도구는 "정해진 모양"만 찾아요. `공일공-1234-5678`처럼 모양이 다르거나, 사진 속 글자는 못 찾아요. 스캔본 PDF는 OCR이 잘못 읽은 글자를 놓칠 수 있어요.
2. **이름은 직접 적어야 가려져요.**
3. **가려도 누군지 알 수 있는 경우가 있어요.** 예: "○○학과 3학년 유일한 외국인 학생" → 이름이 없어도 누군지 알 수 있죠. 이런 세부 내용은 직접 지우거나 흐리게 바꿔 주세요.
4. **이 도구를 썼다고 법적인 '가명처리'가 되는 건 아니에요.** 업무 자료를 외부 AI에 넣어도 되는지는 **소속 기관의 지침**을 먼저 확인하세요.
5. 개인정보가 아니어도 **내부 기밀·미공개 자료**는 가려지지 않아요. 보내도 되는 자료인지 먼저 판단하세요.

## ❓ 자주 묻는 질문

<details>
<summary><b>정말 내 정보가 밖으로 안 나가나요?</b></summary>

네. 모든 처리는 내 인터넷 창 안에서만 일어나고, 외부로 보내는 기능 자체가 없어요.
의심된다면 페이지를 연 뒤 **인터넷을 끊고** 써 보세요. 그래도 똑같이 동작합니다.
(개발 중에 자동 테스트로 확인했을 때도 외부로 나간 요청은 0건이었어요.)
스캔본 PDF의 OCR 엔진만은 처음 쓸 때 **같은 사이트(github.io)에서 받아 오는** 것이고, 내 파일을 보내는 게 아니에요. 이미 한 번 받은 뒤라면 인터넷을 끊어도 그 창에서는 계속 동작해요.

</details>

<details>
<summary><b>휴대폰에서도 되나요? 어떤 브라우저를 써야 하나요?</b></summary>

**최신 Chrome 또는 Edge**를 권장해요. 이 두 브라우저에서 테스트했어요.
Safari, Firefox, 휴대폰 브라우저는 아직 충분히 확인하지 못했어요.

</details>

<details>
<summary><b>AI 답변을 복원했는데 이름표가 그대로 남아 있어요.</b></summary>

AI가 이름표를 살짝 바꿔 쓴 경우예요. (`[지정어_1]` → `[지정어 1]`, `지정어_1` 등)
복원은 이름표가 **글자 하나까지 똑같을 때만** 돼요. AI에게 "대괄호 표시는 그대로 써 줘"라고 부탁한 뒤 다시 해 보세요.

</details>

<details>
<summary><b>개인정보가 아닌데 가려졌어요.</b></summary>

문서번호처럼 숫자 모양이 비슷하면 잘못 가려질 수 있어요.
화면의 「자동 탐지」에서 **해당 종류를 눌러 끄면** 그 종류는 가리지 않아요.

</details>

<details>
<summary><b>"재검사 ✅"가 나오면 안전한 건가요?</b></summary>

"이 도구가 아는 모양은 더 남아 있지 않다"는 뜻이지, "개인정보가 하나도 없다"는 뜻은 아니에요.
처음부터 모양이 달라 못 찾은 정보는 재검사에서도 못 찾아요. 마지막 확인은 꼭 직접 해 주세요.

</details>

<details>
<summary><b>큰 파일도 되나요?</b></summary>

내 컴퓨터 안에서 처리하기 때문에 컴퓨터 성능에 따라 달라요. 수백 쪽짜리 PDF나 아주 큰 엑셀은 느려질 수 있으니, 나눠서 넣어 주세요.

</details>

<details>
<summary><b>한글(.hwp, .hwpx) 파일은요?</b></summary>

둘 다 돼요. **.hwpx는 서식을 그대로 둔 채** 가린 .hwpx 파일로, **.hwp는 글자만 뽑아** 텍스트 파일로 저장해요.
.hwp 서식까지 유지하고 싶다면 한글에서 「다른 이름으로 저장 → .hwpx」로 저장한 뒤 넣어 주세요.
누름틀(클릭해서 입력하는 칸)의 안내 문구처럼 글자 수가 함께 적힌 값은 문서가 깨지지 않도록 건드리지 않아요. 그런 곳에 개인정보가 있으면 재검사가 ⚠️로 알려 줘요.

</details>

일반 사용자는 여기부터는 읽지 않아도 괜찮아요.

<details>
<summary><b>📂 저장소 구성</b></summary>

| 파일 | 설명 |
|---|---|
| `index.html` | 웹 도구 전체 (파일 하나). 필요한 라이브러리가 안에 들어 있어 내려받아 오프라인으로 열어도 동작 (스캔본 OCR만 빼고) |
| `ocr/` | 스캔본 PDF용 OCR 엔진(tesseract.js)과 한국어·영어 학습 데이터. 처음 쓸 때만 불러옴. 출처·해시는 [`ocr/README.md`](ocr/README.md) |
| `pii_guard.py` | 파이썬 명령줄 도구. 여러 파일 일괄 처리, 파일 비밀번호 설정 |
| `tests/test_pii_guard.py` | 탐지 규칙·Word·Excel·한글·텍스트 처리 테스트, 웹과 파이썬 규칙이 같은지 확인 |

</details>

<details>
<summary><b>🐍 파이썬 도구 (여러 파일 한 번에 처리 · 비밀번호 걸기)</b></summary>

```bash
pip install python-docx openpyxl pypdf cryptography msoffcrypto-tool olefile
python pii_guard.py 상담기록.docx 신청자.xlsx 공문.hwpx --words 홍길동,김영희
```

| 옵션 | 설명 |
|---|---|
| `--words 홍길동,김영희` | 자동으로 못 찾는 이름·회사명을 추가로 가림 |
| `--star` | 이름표 대신 별표(`*`)로 가림 (복원 불가) |
| `--partial` | 일부만 가림 (`010-****-5678`, `901023-1******`) — 업무에 다시 쓰기 좋음, 복원 불가 |
| `--map` | 이름표↔원래 값 대응표(`_map.json`) 저장 ⚠️ 개인정보가 들어 있으니 따로 보관 |
| `--lock` | 마스킹과 함께, **원본**에 열기 비밀번호를 걸어 `이름_locked.확장자`로 저장 |
| `--lock-only` | 마스킹 없이 비밀번호만 설정 |

- 원본은 건드리지 않고 `이름_masked.확장자`로 새로 저장해요. 한글 .hwp는 `이름_hwp_masked.txt`, PDF는 `이름_pdf_masked.txt`.
- 스캔본 PDF의 OCR은 파이썬 도구에는 없어요(별도 OCR 프로그램 설치가 필요해서). 웹 도구에서 처리해 주세요.
- 저장한 뒤 결과 파일 전체(시트 이름·수식·링크 주소 포함)를 다시 검사해서, 남은 항목이 있으면 ⚠️로 알려 줘요.
- 비밀번호는 docx·xlsx·pdf에 걸 수 있고, 8자 이상을 두 번 입력해요. **잃어버리면 파일을 열 수 없어요.**
- 잠근 파일은 AI가 읽을 수 없으니, AI에는 `_masked` 파일을 보내세요.
- 파이썬 도구에는 복원 기능이 없어요(`--map`으로 대응표 저장만 가능).
- Excel을 파이썬 도구로 처리하면 차트·도형 등 일부 개체가 빠질 수 있어요(openpyxl 한계). 웹 도구는 그대로 유지해요.

```bash
python pii_guard.py 상담기록.docx --words 홍길동 --lock     # 가리고 + 원본 잠그기
python pii_guard.py 계약서.pdf 신청자.xlsx --lock-only     # 잠그기만
```

<summary><b>⚙️ 동작 방식과 한계</b></summary>

- 탐지는 **정규식**(정해진 문자 패턴) 기반이에요. 규칙은 `index.html`과 `pii_guard.py`의 `RULES`에 각각 있어서, 고칠 때 두 곳을 함께 고쳐야 해요. 한쪽만 고치면 `tests/test_pii_guard.py`가 실패해서 알려 줘요.
- 규칙은 위에서부터 순서대로 적용되고, 먼저 찾은 값은 뒤 규칙이 다시 건드리지 않아요. 꺼 둔 항목이 다른 규칙에 잘못 걸리지 않도록 처리돼 있어요.
- Word·한글(.hwpx)은 문단 단위로 글자를 이어 붙여 검사해요(번호가 여러 서식 조각에 나뉘어 있어도 찾도록). 바꿀 값은 그 값이 시작된 조각에만 넣어 나머지 서식은 유지해요.
- 한글 .hwp(HWP 5.0)는 OLE 복합 파일 안의 `BodyText/SectionN` 스트림을 풀어 문단 글자 레코드(HWPTAG_PARA_TEXT)만 읽어요. 웹은 OLE 구조를 직접 읽고, 파이썬은 `olefile`을 써요.
- 스캔본 PDF는 글자가 없는 쪽만 그림으로 그려 OCR(tesseract.js, 한국어+영어)로 읽어요. OCR 결과에서 `010 - 1234`처럼 숫자 사이에 끼어든 빈칸은 붙여서 검사해요.
- 결과 파일 재검사는 파일 안의 모든 XML·링크 주소·시트 이름·그림 대체 텍스트·한글 미리보기 글자까지 확인해요.
- 처리하지 않는 것: 이미지 속 글자, Excel 차트·도형 글자, 시트 이름, 수식, 한글 누름틀의 글자 수가 적힌 안내 문구.
- 새 탐지 항목은 `RULES`에 한 줄 추가하면 돼요. 예: `['학번', /(?<!\d)20\d{8}(?!\d)/g]` (단순 숫자열은 오탐이 늘 수 있으니 충분히 시험한 뒤 적용).
